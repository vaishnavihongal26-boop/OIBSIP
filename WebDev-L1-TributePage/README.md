# Rosalind Franklin — Tribute Page

## About the Project

This is a tribute page dedicated to Rosalind Franklin, a pioneering scientist whose X-ray crystallography research provided important evidence for understanding the structure of DNA.

## Features

- Professional hero section
- Biography section
- Photograph 51 section
- Timeline of important events
- Inspirational quote section
- Scientific legacy section
- Responsive design for different screen sizes
- Modern typography and color scheme
- Navigation menu

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Wikimedia Commons

## Project Highlights

The page presents Rosalind Franklin's scientific journey, her work with X-ray crystallography, and the importance of Photograph 51 in the study of DNA structure.
