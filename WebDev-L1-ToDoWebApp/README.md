# TaskFlow - To-Do Web App

## OIBSIP Web Development - Task 3

TaskFlow is a modern and responsive To-Do Web App developed using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Edit tasks inline
- Delete tasks
- Pending and completed task sections
- Task counters
- Automatic date display
- Automatic morning, afternoon, evening and night greeting
- Task timestamps
- LocalStorage for saving tasks
- Responsive design for mobile and desktop
- 3D hover effects and smooth task animations
- Sidebar navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
